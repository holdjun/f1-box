# 车队详情页（/teams/{slug}）

日期：2026-08-07
状态：开发中

## 背景与目标

数据地基（R2 vendor + f1db 归档）完成后，网站第一次消费全历史数据：为每个车队提供类似 Wikipedia「F1 赛季成绩」的完整历史页。首站法拉利，模板通用，其余车队随同一模板自动可用。历史参考数据直接放进 Cloudflare D1（f1db 官方 SQLite 的子集），页面运行时用 SQL 取数，不再为每个页面手工生成 JSON。

## 用户可见行为

- /teams/ferrari 打开法拉利详情页：身份头（车队色渐变、logo、全名、国旗）、生涯总计（参赛/胜场/领奖台/杆位/最快圈/积分/冠军数/最佳名次）、1950 年至今逐年历史表（赛季/底盘/引擎/车手/积分/名次）。
- 夺冠赛季行高亮；最新赛季行标记为当前赛季。
- 冠军积分设立前（1950–1957）积分/名次列显示「—」。
- 不存在的车队返回 404 页。
- 旧路由 /{year}/teams/{team} 保持不变（本次不动）。

## 验收标准

- `pnpm check`、`pnpm test`、`pnpm -r build`、`pnpm --filter @f1-box/web test:e2e` 全绿。
- e2e：/teams/ferrari 渲染 77 个赛季行、16 个夺冠行、1 个当前赛季行；未知车队 404；移动端不破损。
- D1 数据库 f1db 含 f1db 参考表子集（scripts/f1db-d1-dump.sh 可再生成），data-sync 定时刷新。
- 预览环境用真实 D1 数据渲染 /teams/ferrari。

## 范围外

- 页面视觉精修（本轮只做功能正确的最小样式）。
- 今年特写区块（当前车手卡、实时积分榜）——后续迭代。
- 车手链接、车队列表页改版、其他车队专属内容。
- 比赛级明细数据（圈速/排位/正赛结果）不进 D1。
