# 车队详情页（/teams/{slug}）

日期：2026-08-07
状态：开发中

## 背景与目标

数据地基（R2 vendor + f1db 归档）完成后，网站第一次消费全历史数据：为每个车队提供类似 Wikipedia「F1 赛季成绩」的完整历史页。首站法拉利，模板通用，其余车队随同一模板自动可用。历史参考数据直接放进 Cloudflare D1（f1db 官方 SQLite 的子集），页面运行时用 SQL 取数，不再为每个页面手工生成 JSON。

## 用户可见行为

- /teams/ferrari 打开法拉利详情页：身份头（车队色渐变、logo、全名、国旗）、生涯总计（参赛/胜场/领奖台/杆位/最快圈/积分/冠军数/最佳名次）。
- 逐赛季结果矩阵（复刻 Wikipedia 样式）：2026 当前季在顶部，逐年代倒序到 1950；每季一块，表头为各分站三字母缩写，每位车手一行（国旗 + 链接到 /drivers/{id}，车手全局页未实现前先 404），格子为名次并带上标 P（杆位）/ F（最快圈）；Ret/DNQ/DSQ 等状态原文显示；格子按结果类型着色。表格上方有颜色图例（胜/领奖台/积分/退赛/DNQ/DSQ + P/F 含义）。每季标题行展示底盘/引擎/轮胎与积分/名次。
- 长页渐进渲染：赛季块用 content-visibility: auto 跳过视口外布局（大范围优化如分页留待后续）。
- 夺冠赛季块高亮；最新赛季标记为当前赛季。
- 不存在的车队返回 404 页。
- 旧路由 /{year}/teams/{team} 保持不变（本次不动）。

## 验收标准

- `pnpm check`、`pnpm test`、`pnpm -r build`、`pnpm --filter @f1-box/web test:e2e` 全绿。
- e2e：/teams/ferrari 渲染 77 个赛季块、16 个夺冠块、1 个当前赛季块（含逐场矩阵与杆位/最快圈上标）；未知车队 404；移动端不破损。
- D1 数据库 f1db 含 f1db 参考表子集（scripts/f1db-d1-dump.sh 可再生成），data-sync 定时刷新。
- 预览环境用真实 D1 数据渲染 /teams/ferrari。
