# 车队/车手目录与详情页年份筛选

日期：2026-08-13
状态：已实现

## 背景与目标

teams/drivers 目录页是全量名单，详情页的逐年成绩矩阵一次渲染全部赛季。用户需要按年份切片：目录页只看某一年参赛的车队/车手，详情页只显示选定一个或多个年份的成绩表。

## 用户可见行为

- /drivers、/teams 顶部新增年份选择栏（All 默认全量 + 1950–2026 降序），点击某年只显示该年参赛车手/车队，卡片显示该年车队；URL 为 ?year=YYYY，可分享可后退。
- /drivers/{id}、/teams/{slug} 的 Season results 上方新增筛选栏（All + 该实体参赛年份降序），可单选、多选、切回全部；选中后只显示对应年份的成绩表，断档提示、转队分隔线跟随所属赛季一起显隐。
- 详情页筛选状态写入 URL（?year=1997,2007），可分享、刷新保持、后退恢复。
- 目录页按年份的名单按名字字母序；全量目录保持现有成就排序不变。
- 同 PR 附带车手详情页矩阵重构：车手表改为车手+队友行（队友行灰色且可链接）、多年多队拆成连续多表并加转队连线、积分与夺冠标记只在首表显示避免拆表重复。

## 验收标准

- driver-repository / team-repository 单测：按年查询 SQL 含 test_driver=0 与年份过滤、行映射、去重；年份列表降序。
- e2e：目录页 ?year=1997 名单被过滤、默认全量；详情页点单年份只剩该 block、多选、All 恢复；转队分隔线随筛选显隐；375px 无横向溢出。
- DEV fixture 补 years 字段（脚本从本地 D1 生成），DEV 下按年查询可用。
- pnpm check / pnpm test / build / e2e 通过；preview 目检桌面与 375px。

## 范围外

- 目录页按年份的成就排序（保持字母序）。
- 卡片上的逐年积分/排名文案。
