# 仓库自动化与发布流程

日期：2026-08-04
状态：开发中

## 背景与目标

初版代码整理完成后，需要一套自动化让仓库健壮运转：需求文档进仓库后，agent 开发、CI 验证、preview 自动部署，用户在网页验收，合并后一键审批发布到 f1-box.com，比赛数据定时自动更新。同时确立代码卫生规则，防止注释、防御代码和死代码无限堆积。

## 用户可见行为

- 每次 PR 自动运行完整验证（类型、测试、e2e、Python），结果在 PR 页面可见。
- 每个分支自动部署到固定的 preview 地址，可在桌面和手机上直接浏览。
- 合并到 main 后，在 Actions 页面点一次 Approve 即发布到 f1-box.com。
- 比赛周末数据每 30 分钟自动更新一次，平时每天一次；也可手动触发。

## 验收标准

- ci / ingest / deploy 三个工作流各成功运行一次。
- preview 页面能看到真实 2026 赛季数据。
- 审批发布后 f1-box.com 与 /api/health 可访问。
- 重复触发 ingest 时 checksum 未变化则跳过上传。
- AGENTS.md 记录开发流程与代码卫生规则，docs/requirements 有需求模板。

## 范围外

- dependabot、分支保护、matrix 构建等附加治理。
- www 子域重定向、D1、监控告警平台。
- 历史赛季数据与检索。
